# Anthropic

AI company; maker of Claude and Claude Code. Relevant here as the author of the
AI-native SDLC playbook and the originator of the `CLAUDE.md` convention that both
that playbook and this wiki's [schema](../CLAUDE.md) use.

## Relevance to this wiki
- Published the [AI-Native SDLC Playbook](../sources/source-anthropic-ai-native-sdlc.md),
  the wiki's first source that *applies* the LLM-wiki pattern to a team workflow.
- `CLAUDE.md` — the file that carries this wiki's schema — is an Anthropic /
  Claude Code convention, which is why the SDLC playbook and the LLM-wiki pattern
  share a substrate. See [Applying the LLM wiki to the AI-native SDLC](../summaries/llm-wiki-applied-to-sdlc.md).
