# Caliper Analytics

A [1EdTech](1edtech.md) standard (2015) defining a common format for capturing and
sharing learning-activity data (learning events), so tools can measure and report
engagement and performance. The **proof-of-concept spec** in the
[One Data, One Meaning](../sources/source-molenaar-one-data-one-meaning.md) talk.

## Relevance to this wiki
- The talk builds **Caliper Analytics as an OKF/LLM-Wiki bundle** — the first
  concrete instantiation of the [OKF-for-1EdTech](../summaries/okf-for-1edtech-specs.md)
  idea, editable in Obsidian + Claude Code, serving humans and agents alike.
- Its events are precisely where the [context dictionary](../concepts/context-dictionary.md)
  bites: a Caliper "Completed" event is interoperable as data but ambiguous in
  meaning until the dictionary pins it down.
- A proposed next step is a "Caliper Analytics Context Dictionary OKF."
